SOAP Web Service

This project sends SOAP XML requests to the local server and receives XML responses. The service supports listing, creating, updating, and deleting tasks.

EndpointPOST /soap
WSDL definitionOpen scrum.wsdl ↗
ProtocolSOAP 1.1 / XML

Available operations

GetTasksReturns all Scrum tasks.
CreateTaskCreates a task with title, assignee, and priority.
UpdateTaskStatusMoves a task between To Do, In Progress, In Review, and Done.
DeleteTaskRemoves a task by ID.

Project overview

Title: Scrum Workflow Automation Using SOAP Web Services

Objective: Demonstrate how a Scrum board can manage tasks through SOAP XML requests and responses.

Technology: HTML, CSS, JavaScript, Node.js built-in HTTP server, SOAP 1.1, and WSDL.

Note: This academic prototype stores tasks in server memory. Restarting the server restores the sample tasks; it is not connected to Jira or a production database.
